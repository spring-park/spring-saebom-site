Hello, and welcome

This is the first post on this site, which mostly means it's a placeholder — a working example to show how a post is put together, and an excuse to write down why this blog exists in the first place.

Why a blog

Between tutoring, coursework, and a small startup, I end up explaining the same ideas more than once — a data structure, a way of framing a problem, something I learned the hard way while planning an event. Writing it down once, in one place, felt like the more useful habit. This is that place.

How this site works

No CMS, no database — just plain HTML and CSS, hosted on GitHub Pages. Every page shares one stylesheet, so a new post automatically looks like the rest of the site. Adding a new one is two steps: duplicate posts/post-template.html, write in it, and add one entry to posts-data.js so it shows up on the blog index. No build step, nothing to install.

What's next

Delete this post whenever the real first one is ready to take its place — or leave it, as a note on how the site started.
