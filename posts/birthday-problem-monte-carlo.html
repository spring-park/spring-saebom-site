The Birthday Problem with Monte Carlo Simulation

Suppose there are 20 students in a class. What is the probability that at least two students have the same birthday? Instead of solving the probability directly with a formula, we can estimate it by repeating the same random experiment many times in Python.

The idea

This is a Monte Carlo simulation. One trial creates 20 random birthdays and checks whether any birthday appears more than once. If we repeat this trial 10,000 times, the fraction of trials with a repeated birthday gives us an estimate of the probability.

  1. Generate 20 random birthdays from day 1 to day 365.
  2. Convert the birthdays to a set.
  3. Check whether there are fewer than 20 unique birthdays.
  4. Repeat the experiment 10,000 times.
  5. Divide the number of matches by 10,000.

The Python code

count = 0

for i in range(10000):

    birthdays = set(np.random.randint(1, 366, 20))

    l = len(birthdays)

    if l != 20:

        count += 1

count / 10000

How it works

1. Create a counter

count = 0 starts a counter for the number of simulated classes that contain at least one shared birthday.

2. Repeat the experiment

for i in range(10000) runs the same random experiment 10,000 times. A larger number of trials usually gives a more stable estimate.

3. Generate 20 birthdays

np.random.randint(1, 366, 20) generates 20 random integers from 1 through 365. Each number represents one day of the year.

4. Why use a set?

A set keeps only unique values. For example, [10, 25, 25, 80] becomes {10, 25, 80}. Therefore, if 20 students produce fewer than 20 unique birthday values, at least two students must share a birthday.

5. Estimate the probability

After all 10,000 trials, count / 10000 calculates the proportion of simulated classes with at least one shared birthday.

With np.random.seed(2019), my simulation returned 0.4115, or about 41.15%. Since this is a random simulation, the exact result can change slightly when a different random seed is used.

What I learned

My first idea was to compare every student's birthday with every other student's birthday. That works, but a set makes the check much simpler because duplicate values are removed automatically.

This problem also shows why simulation is useful. We do not always need to begin with a probability formula. If we can describe the random process clearly, Python can repeat it many times and give us a useful numerical estimate.
